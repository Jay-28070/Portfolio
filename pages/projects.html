Overview

A comprehensive Student Management System built in Java that demonstrates advanced OOP principles, data validation, and user interaction through both console and GUI dialogs.

Key Features

  • Add Students - Create student records with automatic ID generation (5-digit random IDs)
  • View All Students - Display students sorted by ID using bubble sort algorithm
  • Remove Students - Delete student records by name
  • Search Functionality - Find students by name, surname, or ID
  • Update Records - Modify student information with validation
  • Data Validation - Age-grade correlation checks, empty field prevention, numeric validation
  • GUI Error Dialogs - User-friendly error messages using JOptionPane
  • Audio Feedback - System beep alerts for errors

Technical Implementation

  • Object-Oriented Design - Student class with encapsulation (getters/setters)
  • ArrayList Management - Dynamic student collection storage
  • Sorting Algorithms - Bubble sort implementation for ID ordering
  • Exception Handling - Try-catch blocks for NumberFormatException
  • Input Validation - Multiple validation layers for data integrity
  • Business Logic - Age-grade validation (prevents impossible scenarios)

Validation Rules

  • Grades must be between 1-12
  • Students cannot be kept in same grade for more than 3 years
  • Age-grade correlation must be realistic (age - grade between 5-8 years)
  • All fields validated for empty/blank inputs
  • Numeric fields validated for proper integer format

Skills Demonstrated

Java fundamentals, object-oriented programming, data structures (ArrayList), sorting algorithms, exception handling, input validation, GUI components (Swing), and console I/O operations.
