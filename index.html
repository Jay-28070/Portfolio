Overview

A comprehensive Student Management System built in Java that demonstrates advanced OOP principles, data validation, and user interaction.

Key Features

  • Add Students - Create student records with automatic ID generation
  • View All Students - Display students sorted by ID using bubble sort
  • Remove Students - Delete student records by name
  • Search Functionality - Find students by name, surname, or ID
  • Update Records - Modify student information with validation
  • Data Validation - Age-grade correlation checks, empty field prevention
  • GUI Error Dialogs - User-friendly error messages using JOptionPane

Technical Implementation

  • Object-Oriented Design - Student class with encapsulation
  • ArrayList Management - Dynamic student collection storage
  • Sorting Algorithms - Bubble sort implementation
  • Exception Handling - Try-catch blocks for validation

Skills Demonstrated

Java fundamentals, object-oriented programming, data structures (ArrayList), sorting algorithms, exception handling, and GUI components (Swing).
