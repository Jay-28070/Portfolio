officeFlow

Overview

officeFlow is a comprehensive business management application designed to streamline internal services including HR, Maintenance, and IT Support.

Key Features

  • HR Management System - Employee records, leave requests, and performance tracking
  • Maintenance Ticketing - Report and track facility maintenance issues
  • IT Support Portal - Submit and manage technical support requests
  • Employee Management - Create departments as super admin and manage all employees.
  • Real-time Notifications - Stay updated on request status
  • User Authentication - Secure login with Firebase

Technologies Used

Built with HTML, CSS, JavaScript for the frontend, Node.js and Express for the backend API, and Firebase for database management.

Challenges & Learning

This project taught me about building RESTful APIs, Admin hierachy and how to use node.js with express.

Overview
